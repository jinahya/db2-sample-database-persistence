= Exercises
:toc: left
:toclevels: 3

The exercises on the installed `SAMPLE` database of IBM Db2, in its `DB2INST1` schema: a section for each table and view, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise poses a problem; its answer, and what the installed data gives back, are in the `.sql` file.
The output is that of the command line processor, `db2`, with each column narrowed to its widest value; it shows a `DATE` as `MM/DD/YYYY` and a `NULL` as `-`.
An exercise only SQL can answer, a recursive query, a window, a rollup, a function of Db2 or a query into an XML document, is flagged `native-only: true` in `EXERCISES.yaml`.

Run a file as a whole, from the project's directory:

[source,sh]
----
docker cp src/test/sql-exercises/<section>/<NN>_<level>.sql db2-sample-database-persistence:/tmp/ &&
docker exec db2-sample-database-persistence \
  su - db2inst1 -c 'db2 connect to SAMPLE && db2 -tvf /tmp/<NN>_<level>.sql'
----

=== Advanced

[[SAMPLE_DEPARTMENT_A_01]]
==== SAMPLE_DEPARTMENT_A_01: the departments under A00, level by level

Walk the tree of departments from `A00` down along `ADMRDEPT`, and show each department with its depth, `A00` at 0, ordered by depth and `DEPTNO`.
`A00` administers itself, so the walk must not start again from it.
A recursive common table expression, whose recursive part Db2 wants joined in `WHERE`; Jakarta Persistence has none.

.`DEPARTMENT/03_advanced.sql`, SAMPLE_DEPARTMENT_A_01
[%collapsible]
====
[source,sql]
----
WITH TREE (DEPTNO, DEPTNAME, ADMRDEPT, DEPTH) AS (
    SELECT DEPTNO, DEPTNAME, ADMRDEPT, 0
    FROM DEPARTMENT
    WHERE DEPTNO = 'A00'
    UNION ALL
    SELECT d.DEPTNO, d.DEPTNAME, d.ADMRDEPT, t.DEPTH + 1
    FROM DEPARTMENT d, TREE t
    WHERE d.ADMRDEPT = t.DEPTNO
      AND d.DEPTNO <> d.ADMRDEPT
)
SELECT DEPTNO, DEPTNAME, ADMRDEPT, DEPTH
FROM TREE
ORDER BY DEPTH, DEPTNO
----

B01    PLANNING                     A00          1

    SELECT d.DEPTNO, d.ADMRDEPT, d.MGRNO, 1
    FROM EMPLOYEE e, DEPARTMENT d

      AND e.EMPNO = '000290'
